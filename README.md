# HoyoFan

> 米哈游游戏虚构文字打字工具

支持原神、崩坏·星穹铁道、绝区零中的虚构文字输入与预览。

## 支持的字体

| 游戏 | 字体 |
|---|---|
| 原神 | 提瓦特文字、坎瑞亚文字、稻妻文字、须弥文字、赤冠文字、枫丹文字 |
| 崩坏·星穹铁道 | 星穹铁道文字、罗浮文字 |
| 绝区零 | 变体一、变体二 |

## 技术栈

- Vue 3 + TypeScript
- Vite 8
- Tailwind CSS 4
- Element Plus
- Pinia 4

## 开发

**要求：** Node.js ≥ 22

```bash
# 安装依赖
pnpm install

# 启动开发服务器
pnpm dev

# 类型检查
pnpm type-check

# 构建
pnpm build

# 代码检查
pnpm lint
```
